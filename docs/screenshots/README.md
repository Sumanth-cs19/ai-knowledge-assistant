# Portfolio Screenshot Checklist

Add polished screenshots using these filenames:

- `dashboard.png`: summary metrics, recent documents, and quick actions
- `documents.png`: upload area, status badges, and document actions
- `chat.png`: grounded answer with the compact Sources section expanded
- `settings.png`: account and preference controls
- `admin.png`: analytics and user management for an Admin account

Recommended capture size: 1440 x 900 or a similar 16:10 desktop viewport. Use consistent sample data, hide tokens and secrets, and avoid exposing personal email addresses.
